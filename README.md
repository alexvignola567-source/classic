
# FantaLega Classic (GitHub Pages Ready)

This version is built for GitHub Pages.

## Deploy:
1. Upload files to a GitHub repo
2. Go to Settings → Pages
3. Select:
   - Branch: main
   - Folder: /root
4. Save

Your site will be live at:
https://YOUR_USERNAME.github.io/REPO_NAME/

Structure:
- index.html
- assets/css/style.css
- assets/js/main.js
